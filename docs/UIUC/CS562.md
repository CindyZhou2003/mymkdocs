# CS 562 Advanced Topics in Security, Privacy, and Machine Learning

### Agent Harness

Terminology: security goal

-   Confidentiality: Data or personal information not disclosed to unauthorized entities Integrity: Unauthorized entity cannot modify protected information or system functionality e.g., unauthorized write to grades.txt Availability: Data and services are provided to legitimate users when requested Authenticity: the property of being genuine and being able to be verified. Authorization: specifying access rights/privileges to resources Accountability: actions of an entity can be traced

Privilege: System > Developer > User > Model Output > Tool Output
